# Three Adventure website concept

Modern colorful one-page website inspired by the supplied Three Adventure reference design.

- No SVG artwork
- No 3D elements
- Responsive desktop/mobile layout
- Image placeholders ready for the final logo, carnival games, rides, events and gallery photos
- Sections: hero, services, about, games, events, activations, gallery, contact and footer

The deployed version is intentionally image-ready so real assets can be inserted later without rebuilding the overall UI.
